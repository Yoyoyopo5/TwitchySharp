# TwitchySharp.EventSub.Webhooks

This package handles the [EventSub webhooks transport](https://dev.twitch.tv/docs/eventsub/handling-webhook-events/). It is framework agnostic, and can be implemented with any HTTP server implementation. An ASP.NET Core-specific wrapper is provided by the TwitchySharp.EventSub.Webhooks.AspNetCore package.
