# TwitchySharp.EventSub

This package includes all of the types for [EventSub](https://dev.twitch.tv/docs/eventsub/) notifications, along with the polymorphic deserializer needed to create them at runtime.

This does not include bindings for the two EventSub transports. See TwitchySharp.EventSub.Webhooks and TwitchySharp.EventSub.Websocket to put these types into practice.
